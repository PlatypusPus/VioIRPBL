# Data Source

Dataset source: Inside Airbnb public data downloads.

Selected city: Bangkok, Central Thailand, Thailand.

Files:
- `listings.csv.gz`: detailed listings data
- `reviews.csv.gz`: detailed review data

Source page: https://insideairbnb.com/get-the-data/

Direct download URLs used:
- https://data.insideairbnb.com/thailand/central-thailand/bangkok/2026-06-29/data/listings.csv.gz
- https://data.insideairbnb.com/thailand/central-thailand/bangkok/2026-06-29/data/reviews.csv.gz

Downloaded local data files are ignored by git because they are generated dataset artifacts.
